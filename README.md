# Application Culinaire 🍲

Une application Laravel permettant de consulter, créer et partager des recettes culinaires.  
Développée par Aya Zaafouri.

## Fonctionnalités
- Création et gestion de recettes
- Catégories : végétarien, végan, rapide, etc.
- Planification de repas
- Système d’avis sur l’application

## Technologies utilisées
- Laravel 11
- MySQL
- Blade / Bootstrap
