# 🍽️ Application Culinaire Laravel

Bienvenue dans **l'application culinaire développée avec Laravel** !  
Ce projet a pour objectif de permettre aux utilisateurs de **consulter, créer et partager des recettes**, tout en planifiant leurs repas de la semaine.  
Cette application s’adresse aux particuliers passionnés de cuisine 👩‍🍳👨‍🍳.

---

## 🚀 Fonctionnalités principales

### 👤 Côté utilisateur
- 🔍 Consultation des recettes par **catégories** :
  - Végétarien 🥗
  - Végan 🌱
  - Léger 🍃
  - Rapide ⚡
  - Minimaliste 🍞
  - Enfants 🍪
  - Événements 🎉
  - Cuisine tunisienne 🇹🇳  
- ➕ Création et partage de nouvelles recettes
- ❤️ Système d’avis sur **l’application**
- 🗓️ Planification des repas pour la semaine
- 📸 Ajout d’images pour chaque recette
- 🔐 Gestion de compte (prévue dans le Sprint 3)

### 🛠️ Côté administrateur
- 📋 Gestion des recettes (ajout, modification, suppression)
- 🧾 Gestion des avis utilisateurs concernant l’application
- 🗂️ Organisation des recettes par catégories

---

## ⚙️ Installation et exécution

### 1️⃣ Cloner le projet
```bash
git clone https://github.com/Eyazaafouri/re7.git
cd re7
````

### 2️⃣ Installer les dépendances

```bash
composer install
npm install
```

### 3️⃣ Configurer l’environnement

Crée un fichier `.env` à la racine du projet :

```bash
cp .env.example .env
```

Puis modifie les informations de connexion à ta base MySQL.

### 4️⃣ Générer la clé d’application

```bash
php artisan key:generate
```

### 5️⃣ Lancer le serveur local

```bash
php artisan serve
```

Accède à l’application sur :
👉 [http://localhost:8000](http://localhost:8000)
